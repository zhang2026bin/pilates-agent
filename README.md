# 普拉提工作室 Agent

一个面向普拉提工作室的 AI 运营搭档：**专业教练 + 线上获客 + 客户管理 + 私域社群 + 自媒体 + 销售转化**。

当前实例服务于临汾「伊人普拉提」（社区型精品工作室）。

## 它解决什么问题

工作室主理人通常一个人干六件事：上课、写内容、回私信、追客户、维护群、做活动。这个 Agent 把六件事的 SOP、话术、判断标准固化下来，让 AI 能直接给"能说出口的话"和"下一步动作"，而不是泛泛的建议。

## 安装（DSH）

```powershell
git clone https://github.com/zhang2026bin/pilates-agent.git
cd pilates-agent
.\install.ps1
```

脚本会自动做四件事：

1. 把 preset 里的绝对路径改写成本仓库的 `agent/`
2. 设置 `STUDIO_APP` 环境变量（默认 `D:\Downloads\普拉提`，可用 `-StudioApp` 指定）
3. 安装 `pilates-studio` 技能到 `~/.agents/skills/`
4. 安装插件包，并把 `dsh-agent-pilates` 加进 profile 的 bundles

```powershell
# 如果程序不在默认位置
.\install.ps1 -StudioApp "E:\apps\普拉提"
```

> 需要 `dsh` 命令在 PATH 中。重启应用后在 Agent 列表选择 `pilates`。

## 怎么用

直接在对话里说目标即可，例如：

- 「这周给我 5 条小红书选题，要临汾本地、产后妈妈向」
- 「客户体验完说太贵了，帮我想三句回应」
- 「一个产后 14 个月、久坐、腰酸的客户，第一次课怎么排」
- 「设计一个 7 天体验群 SOP」

它会先判断卡在漏斗哪一环，再给原话、依据、合规校验和下一步。

## 知识来源与时效

- 项目情报来自 2026-05 的项目档，**价格需主理人确认**
- 最新打法来自 2026-09/10 的预售项目归档
- 教练专业基线是通用基线，**需持证教练复核**，尤其孕产与腹直肌分离部分

## 与本机教练助手系统的集成

`knowledge/09_教练助手系统.md` 说明如何通过**只读桥脚本**读取本机课序引擎（Node + SQLite，`data/studio.db`）的真实数据：

```powershell
node app/agent-bridge.js client 李姐
node app/agent-bridge.js today
node app/agent-bridge.js week
```

Agent 在涉及具体客户、课表、复测时**先取数再回答**；桥是只读的，排课、扣次、改档案仍由教练在 App 里完成。

## 边界

不做医疗诊断；孕期、术后、急性疼痛、腹直肌分离 ≥2 指、盆底功能障碍必须转介；不承诺疗效与减重数字；正文不留联系方式。
