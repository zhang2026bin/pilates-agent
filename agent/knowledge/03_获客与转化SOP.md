# 03 · 线上获客与转化 SOP

## 一、漏斗与指标
```
曝光 → 互动（赞藏评） → 主页/私信 → 体验课到店 → 成交 → 续费/转介绍
```
| 环节 | 关键动作 | 参考基准（冷启动期） |
|---|---|---|
| 曝光 | 选题 + 本地标签 + 发布时段 | 单篇 3000–10000 |
| 互动 | 钩子标题 + 评论区引导 | 收藏率 8–15% |
| 私信 | 主页简介 + 置顶 + 评论回引导 | 每 1000 曝光 2–5 条 |
| 到店 | 体验课邀约 + 确认 + 提醒 | 私信→到店 30–50% |
| 成交 | 体验课流程 + 报价 + 异议处理 | 到店→成交 30–50% |
| 续费 | 客户管理 SOP | 续费率 50%+ |

> 基准是行业经验值，不是承诺；用自己前 4 周的数据校准。

## 二、内容获客（详见 06）
- 90% 痛点共鸣 + 10% 专业；本地内容带临汾元素。
- 每条内容只做一件事：让人"觉得说的是自己"，然后想私信。
- 不直接卖课；引导语放在评论区/主页，不放正文。

## 三、私信转化五步
1. **共情**：先回应她的痛点（"生完孩子腰一直酸，太常见了"），不急着介绍。
2. **问诊**：3 个问题（产后多久/哪里最不舒服/平时能练几次）。
3. **给判断**：基于回答给 1 条具体建议（不是课程）。
4. **邀约**：给两个时间选项，不给开放问句（"周三上午 10 点或周六下午 3 点，哪个方便？"）。
5. **确认**：发地址 + 到店提醒 + 需要带什么；24 小时前再提醒一次。

**示例（产后妈妈）**
> 她：生完一年了肚子还像五个月
> 你：一年还在这个状态很常见，先别急着练卷腹。冒昧问一下，是剖还是顺？现在抱娃久了腰会不会酸？
> 她：顺产，腰特别酸
> 你：那大概率是先要处理呼吸和核心激活，不是减脂。方便的话来做个 20 分钟体态评估，我帮你看下腹直肌分离和骨盆位置，不收费。

## 四、体验课流程（60 分钟）
| 环节 | 时长 | 要点 |
|---|---|---|
| 接待 + 问诊 | 10 | 主诉、孕产史、目标、怕什么 |
| 体态评估 | 15 | 拍照（授权）、静态+动态、呼吸 |
| 体验训练 | 20 | 3–4 个动作，让她"感觉到差别" |
| 报告 + 方案 | 10 | 3 条结论 + 推荐频次 + 预期节奏 |
| 报价 + 下一步 | 5 | 只给一个推荐方案 + 两个备选 |

**关键**：体验课不是"上课"，是"让她相信你懂她的身体"。成交发生在报告环节，不在训练环节。

## 五、报价结构
- 入口：体验课（免费/39–69）+ 预售 100 抵 1000。
- 主力：私教 10 节包（按当前 200/节，10 节 2000；可设计 12 节赠 1 节）。
- 走量：团课 5 节 100（引流）→ 转 20 节 / 月卡。
- 升级路径：团课 → 小班 → 私教 → 私教包 → 年度陪伴。
- **不做 9.9 引流**，伤品质感知。

## 六、异议处理
| 异议 | 回应要点 |
|---|---|
| 太贵了 | 拆分单次成本 + 对比一次按摩/医美；给入门小包降低决策 |
| 没时间 | 给"每周 2 次 × 45 分钟"的最小方案；固定时段 |
| 怕坚持不了 | 打卡群 + 固定教练 + 4 周复评，把"坚持"变成"有人盯" |
| 怕受伤 | 先评估后训练 + 全程降阶 + 疼痛即停 |
| 和家人商量 | 给一份"方案说明"让她带回去（专业感） |
| 再想想 | 约定具体回访时间，不逼单；3 天后发一条"今天有个学员和你情况一样" |

## 七、本地渠道
1. **美团/大众点评**：上架体验课，冲评分（前 20 条评价最关键）。
2. **社区**：御景水城/御华苑周边地推 + 免费体态评估（15 分钟）。
3. **异业**：月子中心、母婴店、产后恢复机构、儿童培训机构（互推）。
4. **企业**：写字楼午间团课（8 人起），换员工福利曝光。
5. **转介绍**：老客带新，双方各赠 1 节；做成卡片而不是口头说。

## 八、每周获客动作清单
- 发布 5–7 条内容（小红书为主）
- 私信回复 ≤ 2 小时
- 体验课邀约 ≥ 5 人
- 到店体验 ≥ 3 人
- 老客转介绍触达 ≥ 5 人
- 复盘 1 次（曝光/私信/到店/成交）
