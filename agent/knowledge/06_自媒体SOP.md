# 06 · 自媒体 SOP（小红书 / 公众号 / 抖音 / 视频号）

## 一、平台分工
| 平台 | 角色 | 内容比例 | 频率 |
|---|---|---|---|
| 小红书 | 本地获客主阵地 | 80% 引流共鸣 + 20% 专业 | 日更 1 条 |
| 公众号 | 深度信任 | 50% 本地女性故事 + 50% 深度干货 | 周更 1–2 篇 |
| 抖音 | 同城曝光 | 短视频/跟练/探店 | 每周 3–5 条 |
| 视频号 | 熟人转发 | 与抖音同素材，竖版 | 每周 3 条 |

## 二、选题：七类欲望（来自项目规则）
| 欲望 | 内容方向 | 示例 |
|---|---|---|
| 健康欲 | 身体痛苦 + 解决 | "带娃 3 年，我的腰已经废了" |
| 舒适欲 | 轻盈放松 | "练完像卸掉 10 斤" |
| 优越感 | 穿衣拍照被夸 | "买衣服直接拿 S 码" |
| 情感欲 | 自我价值 | "当妈后第一次为自己花钱" |
| 食欲 | 不用节食 | "顿顿吃火锅还瘦了" |
| 性魅力 | 紧致气质 | "好身材不是瘦，是紧致" |
| 求知欲 | 避坑揭秘 | "花了 2 万办卡总结的避坑指南" |

本地选题补充：临汾宝妈、鼓楼/御景水城/汾河公园、接送孩子、临汾话梗。

## 三、标题公式
1. 数字 + 痛点 + 结果：`临汾产后恢复的 3 个坑，我花了 2 万才总结出来`（对外不用"修复"）
2. 身份 + 反差：`35 岁被当成 25 岁，我只做对了一件事`
3. 自测 + 方案：`骨盆前倾自测：3 个动作对照，中 2 个就要练`
4. 避坑 + 地域：`在临汾办健身卡前，先看这 4 条`

## 四、发布节奏（避开整点）
| 时间 | 平台 | 内容 |
|---|---|---|
| 8:50 | 小红书 | 早间：通勤/起床/带娃场景 |
| 12:35 | 小红书 + 视频号 | 午间：轻干货、办公室场景 |
| 20:35 | 小红书 + 抖音 + 视频号 | 晚间：故事、案例、深度 |

## 五、配图规范
- 人物统一"甜妹/亲和"风格，宝妈形象，不髙冷。
- 纯视觉图：**无文字、无水印、无二维码**。
- 场景真实：家里、公园、教室、咖啡厅；光线自然。
- 小红书 3–4 张；公众号 2–3 张；封面单独设计。

## 六、内容结构
`钩子（1–2 行）→ 共鸣（说中她的处境）→ 干货（3 点，可执行）→ 轻引导（评论区/主页）`
- 全文不出现价格、不出现微信号。
- 结尾提问，引导评论（提升互动）。

## 七、30 天排期示例
- 第 1 周：3 条痛点（产后/肩颈/假胯宽）+ 1 条人设
- 第 2 周：2 条干货 + 1 条学员变化 + 1 条本地生活
- 第 3 周：1 条避坑 + 1 条自测 + 1 条活动 + 1 条答疑
- 第 4 周：复盘爆款，做系列；公众号 1 篇深度

## 八、复盘指标（每周）
| 指标 | 看什么 | 动作 |
|---|---|---|
| 曝光 | 有没有进流量池 | 低于 2000 换选题/封面 |
| 收藏率 | 干货价值 | <5% 加步骤图/清单 |
| 涨粉 | 人设吸引力 | 掉粉查内容是否跑偏 |
| 私信 | 转化意愿 | 少则改引导语 |
| 到店 | 最终目的 | 少则查私信话术与邀约 |

## 九、禁止
- 纯教学、动作演示为主的内容（没流量）
- 直接卖课、硬广、价格表
- 夸张对比图、P 图
- "最专业/第一/唯一"等绝对化用语
- 搬运不本地化
