# 02 · 教练专业基线

> 这是"判断依据 + 安全边界"，不是教材。具体动作细节以工作室认证体系为准；超出范围一律转介。

## 一、评估流程（首次 30–40 分钟）
1. **问诊**：主诉、疼痛部位与时间、孕产史、手术史、运动史、职业习惯（久坐/抱娃）、目标。
2. **静态评估**（侧面/正面/背面，拍照留档需授权）：
   - 侧面：耳垂–肩峰–大转子–膝–外踝是否一条线；骨盆前倾/后倾；肋骨外翻；头前引。
   - 正面：高低肩、骨盆侧倾、膝内扣、足弓塌陷。
   - 背面：肩胛对称、脊柱侧弯迹象（明显者转介）。
3. **动态评估**：过头深蹲、单腿站立、主动直腿抬高、胸椎旋转、踝背屈。
4. **呼吸评估**：是否胸式浅呼吸、是否憋气、肋廓能否 360° 扩张。
5. **核心评估**：腹横肌激活（仰卧屈膝，咳嗽/呼气时下腹是否收紧）、腹直肌分离（产后，指宽 + 深度）。
6. **结论**：3 条以内，写成"问题 → 影响 → 训练优先级"，不写诊断。

## 二、六条训练原则
1. 呼吸优先：先建立肋间呼吸，再谈动作。
2. 中立位优先：骨盆中立、肋骨下沉，再加载。
3. 质量 > 数量：宁可 6 次标准，不做 15 次代偿。
4. 渐进：垫上 → 小器械 → 器械；闭链 → 开链；双侧 → 单侧。
5. 疼痛即停：任何刺痛、麻、放射痛立即停止。
6. 可复测：每 4–6 周复评一次，用同一套测试对比。

## 三、动作库（按能力分级，不按花哨程度）
**呼吸与激活**：肋间呼吸、仰卧 90-90 呼吸、死虫式（降阶/进阶）、骨盆卷动。
**核心**：百次呼吸（降阶：屈膝抬腿）、单腿伸展、交叉卷腹（有腹直肌分离者慎用）、平板支撑（跪姿/标准）、侧平板（跪姿）。
**脊柱与髋**：猫牛、脊柱逐节卷动、桥式（臀桥/单腿桥）、四足髋伸、蚌式、侧卧抬腿。
**上肢与肩颈**：墙天使、俯身 Y-T-W、肩胛俯卧撑、颈深屈肌训练。
**平衡与整合**：单腿站立、分腿蹲、游泳式、侧卧全身整合。
**小器械**：弹力带（划船/侧向走）、普拉提圈（大腿内侧/手臂）、小球（核心激活）。

## 四、团课编排（45–60 分钟）
- 热身 8–10 分钟：呼吸 + 脊柱活动 + 髋/肩激活。
- 主体 30–40 分钟：核心 2 组 + 臀腿 2 组 + 上肢/肩颈 1 组 + 平衡 1 组，组间 45–60 秒。
- 放松 5–8 分钟：拉伸 + 呼吸 + 1 个"今天带走什么"的提示。
- 强度分级：给 2 个降阶版本，确保 0 基础能跟上。

## 五、私教 8 次课框架（示例，按评估调整）
1. 评估 + 呼吸 + 核心激活
2. 骨盆中立 + 桥式进阶
3. 核心稳定 + 死虫进阶
4. 髋主导（硬拉模式）+ 臀中肌
5. 肩颈与胸椎活动度
6. 单侧稳定与平衡
7. 整合训练（复合动作）
8. 复评 + 家庭作业 + 下一阶段方案

## 六、剂量与频率
- 团课：每周 2–3 次；私教：每周 1–2 次 + 家庭作业 2 次。
- 预期感受：2 周"身体变轻"、4 周"体态有变化"、8–12 周"照片可对比"。
- 不承诺具体减重数字，只承诺频次与复评。

## 七、禁忌与转介（硬边界）
- 急性疼痛/外伤/术后 → 就医，不训练。
- 孕期 → 孕产普拉提认证教练。
- 腹直肌分离 ≥ 2 指 → 先评估（指宽 + 深度），降阶训练 + 先做呼吸与深层核心激活，不做卷腹类；分离未改善不加负荷。（对外不用"修复"，说"改善/恢复"）
- 盆底功能障碍（漏尿/下坠感）→ 盆底康复评估。
- 高血压/眩晕/视网膜问题 → 避免倒置、憋气、头低于心脏。
- 脊柱侧弯明显/结构性问题 → 骨科或康复科评估后再定方案。
