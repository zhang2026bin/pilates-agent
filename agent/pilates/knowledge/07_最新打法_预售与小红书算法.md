# 07 · 最新打法（2026-09/10）：预售、话术、小红书算法

## 一、项目铁律
1. 预售期核心任务：**每天收 100 元定金**，收完锁定到店日期。
2. 定金三保障：100 抵 2000 / 不来换 3 节课（1 私教 + 2 小班，三个月有效）/ 占名额不排队。
3. 定金不可退，用换课兜底；预售期不承诺提前到店体验。
4. 目标拆解：想收 N 个定金 → 至少开口 3N → 至少拦下 10N。
5. 每天复盘：开口 / 拦下 / 聊深 / 定金，四个数。

## 二、地推话术 v12.0（当前主用）
**筛选 SOP**
1. 看：一个人走 / 脚步慢 / 眼神飘 / 等位休息 / 带娃慢走。
2. 问住址："姐，你是住这附近，还是在这边上班呀？"——住附近才是目标。
3. 按人群给钩子：宝妈 / 上班族 / 无特征。

**效果金句（三处固定用法）**
- 短版："普拉提的效果，照镜子看得见——背直了、腰紧了、人精神了。"
- 用法：① 开场筛完住址先抛；② 价值呈现时效果在前、活动在后；③ 被拒绝时当"回马枪"。
- 宝妈版 / 上班族版 / 情侣版各有变体。

**加微信（第一目标）**："我加您微信，把活动和地址发您，不办卡不花钱，先把名额占上，没空随时删。"

**六种拒绝应对**：不需要 / 太远 / 没时间 / 已有健身卡 / 再想想 / 已有其他馆——每种收尾都补效果金句。

**合规对照**
- 能说：背直了、肩开了、站姿挺拔、腰腹紧了、线条好看、松快、有劲、产后恢复、松垮改善。
- 不能说：修复、治疗、矫正、康复、漏尿、骨盆前倾修复、保证、一定、X 天见效、减 X 斤、练完年轻十岁。

## 三、定金成交话术（无风险版）
现场说："100 块三样保障：抵 2000、来不了换 3 节课、名额占上不排队。三个保障怎么算都不亏。"
- 犹豫："这 100 不是消费，是占位。"
- 能不能退："能退，但基本都转成课。"
- 收后确认："名额锁好了，到店前一天提醒你。"

## 四、体验课转化五步
1. 身体评估反馈（点出可改善的问题）
2. 塑造价值（1 对 1 全程盯动作）
3. 处理价格异议（拆单次成本 / 对比）
4. 制造紧迫感（名额 / 恢复原价）
5. 临门一脚（"刷卡还是微信？" / "先帮你登记名额"）

## 五、加微信 72 小时黄金期
- 第 1 天：欢迎语 + 开业攻略，不推销。
- 第 2 天：专属隐藏福利（送 1 节课）。
- 第 3 天：到店核销提醒。
- 最多跟进 3 次，不骚扰。

## 六、小红书算法（2026 版）
- 推荐得分 = 基础质量 ×0.3 + 用户互动 ×0.4 + 商业价值 ×0.2 + 社交关系 ×0.1 − 违规扣分。
- CES = 赞×1 + 藏×1 + 评×4 + 转×4 + 关注×8。
- 四道闸门：机器初审 → 人工复审 → 初始池 200–500 曝光 → 晋级（CES≥0.7 / 停留>45 秒 / 互动率>5%）。
- 搜索流量已破 55%：标题前 10–20 字放长尾词，正文自然融入 3–5 次，标签 3–5 个，1 小时内作者自评。
- **POI 挂载提升约 70% 曝光**；新号前 3–7 天别发营销内容。
- 内容配比：70% 痛点干货 + 20% 场景种草 + 10% 福利转化。
- 四类高转化：知识科普/痛点解决 40% + 真实案例 30% + 门店实景 20% + 活动福利 10%。
- 转化路径：痛点种草 → 场景种草 → 福利转化 → 到店体验。
- 三级产品矩阵：引流体验课（99/3 节 + 体测）→ 预售次卡 → 特色私教/季卡。

## 七、合规留资与限流红线
- 留资只用三工具：商家名片 / 服务留资卡 / 私信快捷菜单。个人号直接写微信 100% 被封。
- 站外导流零容忍（含谐音、图片暗号）。
- 极限词：最 / 第一 / 顶级 / 天花板 / 唯一 / 100% 有效 / 根除。
- 疗效暗示、AI 内容不标注、低质商销笔记，都是限流项。

## 九、复盘心法（四条）
1. 转化漏斗：筛选先行 → 利益开场 → 效果勾人 → 微信占位 → 现场收定金 → 确认锁预期。
2. "效果"是最高效卖点：专业讲十句不如"照镜子看得见"一句，但必须真实可感知且合规。
3. 小红书不靠广告，靠痛点种草 + 搜索卡位 + POI。
4. 店型决定人设，不能一套话术打所有店。
