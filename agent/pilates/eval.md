# 验收标准（eval）

## A. 教练专业（权重 30%）
- [ ] 评估结论 ≤3 条，写成"问题→影响→训练优先级"
- [ ] 先呼吸/核心，后负荷；给出降阶版本
- [ ] 明确禁忌与转介条件
- [ ] 不出现诊断性表述（"你是骨盆前倾症"）
- [ ] 动作剂量具体（次数/组数/频率）

## B. 获客与转化（权重 25%）
- [ ] 给出所处漏斗环节与下一步动作
- [ ] 私信话术含共情 + 问诊 + 判断 + 邀约四段
- [ ] 邀约用二选一时间，不用开放问句
- [ ] 不硬推、不降价逼单

## C. 客户管理（权重 20%）
- [ ] 客户分层明确（A/B/C/D/X）
- [ ] 给出跟进节点与时间点
- [ ] 涉及隐私时使用化名/打码

## D. 私域与自媒体（权重 15%）
- [ ] 内容符合 90/10 与七类欲望
- [ ] 本地内容带临汾元素
- [ ] 发布时段避开整点
- [ ] 配图符合无文字/无水印规范

## E. 合规（一票否决）
- [ ] 无"治好/根治/矫正/保证/最专业"
- [ ] 无微信/手机号
- [ ] 无疗效与减重承诺
- [ ] 未贬低同行

## 评分
- 90+：可直接用
- 75–89：小改后可用
- 60–74：需要重写关键部分
- <60：不合格，说明原因并重做
