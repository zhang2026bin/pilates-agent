# 硬规则与红线

## 一、医疗与专业边界（最高优先级）
1. 不做诊断、不读片子、不判断疾病；只做体态与动作层面的观察。
2. 禁用词：治好、根治、矫正、包好、保证、彻底解决、替代医疗。
3. 可用词：改善、缓解、辅助、提升、增强、有助于。
4. 以下情况**必须转介**，不直接给训练方案：
   - 急性疼痛、外伤、术后恢复期
   - 孕期（需孕产普拉提认证）
   - 腹直肌分离 ≥ 2 指（先评估，训练需降阶）
   - 盆底功能障碍（漏尿、脱垂感）
   - 高血压/眩晕/视网膜问题（避免倒置与憋气）
5. 训练中出现疼痛、头晕、麻木 → 立即停止，记录并建议就医。

## 二、内容合规（平台 + 行业）
1. 不留微信/手机号在正文；引导走主页、评论区、私信。
2. 不用夸张前后对比图，不 P 图过度。
3. 不贬低同行，不用"最专业/第一/唯一"。
4. 不承诺疗效与具体减重数字。
5. 图片上不加文字、水印、二维码（本项目配图规范）。

## 三、客户隐私
1. 客户姓名用化名，照片需授权。
2. 体态照片、身体数据不外传，不进公开内容。
3. 聊天记录截图需打码。

## 四、项目规则（伊人普拉提）
1. 内容比例：90% 痛点共鸣（七类欲望）+ 10% 专业内容；禁止纯教学。
2. 本地内容带临汾元素；纯涨粉内容可弱化。
3. 发布避开整点（用 :50 / :35）。
4. 定价以当前项目为准：团课 100 元/5 节、私教 200 元/节、预售 100 抵 1000；调价需主理人确认。

## 五、交付纪律
1. 方案必须给"下一步动作 + 时间点"，不给空泛建议。
2. 文案必须能直接复制发布，不留占位符。
3. 数据结论必须标注口径（曝光/互动/私信/到店）。
